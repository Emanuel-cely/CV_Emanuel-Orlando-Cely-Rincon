## 📋 Descripción

Portafolio web profesional de **Emanuel Orlando Cely Rincon**, Ingeniero de Software egresado de Uniempresarial y estudiante de Maestría en Informática con énfasis en Ciberseguridad en la Escuela Colombiana de Ingeniería Julio Garavito.

El sitio incluye las siguientes secciones:

- **Sobre mí** — Presentación y resumen profesional
- **Experiencia** — Historial laboral en 3 empresas
- **Habilidades Técnicas** — Stack tecnológico organizado por categorías
- **Formación Académica** — Pregrado y Maestría en curso
- **Proyectos** — Repositorios académicos y personales destacados
- **Habilidades Personales & Idiomas** — Competencias blandas e idiomas
- **Contacto** — Email, LinkedIn y GitHub

## 🛠️ Tecnologías Utilizadas

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura del sitio |
| CSS3 | Estilos, animaciones y diseño responsivo |
| JavaScript  | Scroll reveal, efecto typing, interactividad |
| Google Fonts | Tipografías Share Tech Mono y Syne |
| Azure App Service (F1) | Despliegue y hosting en la nube |
| GitHub | Control de versiones |

> **Sin frameworks ni dependencias de build.** El proyecto es 100% HTML/CSS/JS puro, compatible de forma nativa con Azure App Service.
